# Specular Button

Vue adaptation of the requested React Bits SpecularButton-JS-CSS component.

Source: https://github.com/DavidHDev/react-bits/tree/main/src/content/Components/SpecularButton
Retrieved: 2026-11-13. Original author: David Haz.

The original WebGL shader and light controller are retained. React hooks are replaced with Vue lifecycle hooks; styling uses Finenic's Manrope and dark button surface. A static edge remains when WebGL is unavailable or reduced motion is enabled. No React runtime or shadcn configuration is needed.
