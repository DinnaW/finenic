# Magic UI Animated List

Adapted from https://magicui.design/r/animated-list.json and https://magicui.design/docs/components/animated-list (MIT, license included).

The official React component's sequential reveal, reversed notification order, layout transitions, and spring parameters are retained with Vue and the project's existing `motion-v`. The entrance starts at scale .96, the demo list is bounded to three entries and cycles, and timers pause offscreen, in background tabs, with the demo pause control, and for reduced motion. No React runtime or shadcn project migration is required.
