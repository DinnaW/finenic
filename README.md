# finenic hero
Vue 3 + Tailwind CSS 4, built with Vite.

Run `npm install`, then `npm run dev`. `npm run build` produces `dist/`. `npm test` validates domain normalization and invalid inputs.

Scope: responsive header and hero, domain search UI, extension selection, expandable navigation, mobile navigation, and contextual product panels. Domain search generates candidate names and links to ICANN registration lookup. It does not assert availability, provide prices, or register domains. Connect an authorized registrar API before offering purchases.

Brand name supplied by user. Navigation is provisional pending the sitemap. The decorative browser card is illustrative. No customer statistics, reviews, or service guarantees are asserted.

Design references: https://qarin.framer.website/ (airy SaaS composition and blue depth), https://dribbble.com/search/domain (domain-focused interaction inspiration), https://webflow.com/list/cloud (hosting presentation). Aurora revision inspired by https://reactbits.dev/backgrounds/aurora with an original Vue WebGL implementation, a static fallback, and pause/reduced-motion support. Manrope remains self-hosted.

Latest direction: user-supplied stepped black hero reference, with original CSS prism columns and Motion for Vue entrance animation. Supersedes Aurora.
